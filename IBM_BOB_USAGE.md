# IBM Bob Usage in GeoPulse_AI

**GeoPulse_AI** is an environmental monitoring and analysis platform that combines location-based environmental information, interactive maps, vegetation analysis, and environmental insights.

## How IBM Bob Was Used

IBM Bob was used as an **AI-assisted development tool** during the development of GeoPulse_AI.

It helped us with:

* Developing and improving the application UI
* Creating and refining frontend components
* Implementing map and location-based features
* Building environmental data visualization
* Integrating and presenting NDVI-based vegetation analysis
* Debugging and fixing development issues
* Improving the overall user experience

## Development Workflow

We used IBM Bob through a simple iterative workflow:

**Idea → Prompt → Development → Testing → Debugging → Improvement**

IBM Bob helped convert our requirements into working application components and reduced development time.

## Key Contribution

IBM Bob supported the technical development of GeoPulse_AI, while the project concept, feature selection, testing, and final decisions were made by our team.

**Project:** GeoPulse_AI
**Technology:** IBM Bob
**Domain:** Environmental Monitoring & Analysis
